## Desk: every NY area drives the price (Manhattan bug), 2026-10-13 (local only, not pushed)
Evidence: `docs/evidence/locality-race/`.
- **Symptom**: in an internal **production** build, choosing Manhattan on the desk still priced 97110 at the Rest of NY $28.27 instead of $32.43, while the scope line said Manhattan.
- **Cause**: a race in `src/components/desk/desk-page.tsx`, there since the locality picker was added (e782619). Choosing an area starts `loadRates(newArea)`, but the old area's `rateSet` stayed in state and the "Price this note" button stayed enabled. In a production build that load (fetch + parse of the 2.4 MB `pfs-2026.json`, again on every change, then the locality pass) took over 3 s, so a click priced with the previous area's amounts. The scope line was read live from `rateSet`, so it changed to Manhattan after the load and labelled a Rest of NY figure "Manhattan". Older evidence passed because e2e internal ran against the **dev** server, where the load finished before the click. A bisect found no commit that broke it: 34fde5c fails the same way on a production build, and the pricing data and logic (`localityPrices`, `runLane`) were right for all 5 areas throughout.
- **Fix**: `RateSet` now carries the `key` it was computed for. `ratesFor(set, locality)` in `src/lib/pricing/rates.ts` returns the set only when it matches the locality on screen. The desk prices only with that set; while the new area loads, the button is disabled and reads "Loading the fee file". A result stores its own `scope` and `release` (and the worksheet line uses it), so the label can never drift from the amounts. `pfs-2026.json` is fetched once and reused (it is retried after a failure).
- **Checks**: lane-check +12: for each of the 5 NY areas, the real `loadRates` (with a stubbed fetch) plus `runLane` gives 97110 at that area's file amount (2827, 3243, 3290, 3111, 3266), recomputed independently from RVUs × GPCIs × CF, with that area's scope; a set for one area is never accepted for another; 5 distinct amounts; and the desk page prices only through `ratesFor`. e2e internal: walks all 5 areas in the built UI (desktop and phone).
